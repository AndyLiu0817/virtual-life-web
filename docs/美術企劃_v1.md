## 0. 原則（先讀再畫）

1. **可上市標準，不是「比現在好看一點」。** 標題畫面、棋盤、角色、介面都必須達到玩家會願意截圖分享、也經得起商店頁或宣傳圖檢視的完成度。暫代圖、色塊、emoji、純 CSS 幾何棋盤，都不能當作上市畫面。
2. **只借鏡玩法與「感覺」，不借用原作資產。** 本作為原創遊戲。可參考《虛擬人生 2》（明日工作室，約 2000）的視覺氣氛（Q 版棋子走在手繪風景地圖上、溫暖濃郁的色彩、有表情的角色與事件畫面），但**禁止**複製或改繪原作角色、神祇、怪獸、地圖布局、格子圖示、標誌、卡片、字型、UI 金屬框與儀器、動畫與文案。
3. **最終畫稿由 Andy 的美術團隊繪製。** AI 產出僅可在 Andy 同意後，用於風格探索或內部草稿，不可直接進遊戲、不可當成定稿、不可冒充手繪完成品。
4. **同一套世界觀貫穿全作。** 棋盤 Q 版、事件立繪、神祇、小遊戲與介面必須像同一個世界，不能「標題很精緻、盤面像示意圖」。
5. **觸控優先、直向橫向都能玩。** 美術要為手機直向與 MuMu／桌機橫向各留一套排版，而不是只做一張大圖再硬縮。

## 1. 《虛擬人生 2》視覺觀察：什麼讓它「像虛擬人生 2」

資料來源：2000 年前後刊物對地圖與畫面的描述、公開遊戲介紹、以及公開的 640×480 遊戲畫面（標題選單與地圖遊玩畫面）。以下只整理「感覺從哪來」，作為借鏡，不當臨摹範本。

### 1.1 畫面由兩種調性組成（這是記憶點）

《虛擬人生 2》並不是從頭到尾同一種畫風，而是**兩種層次併用**：

- **標題／宣傳層：** 偏戲劇化。深色背景、金色魔法陣光暈、偏寫實或半 CG 的人物全身像、金屬感標題條與米色選單按鈕。給人「這是一套完整的商業遊戲」的第一印象。
- **遊玩層：** 偏親切可愛。角色在地圖上是 **Q 版／大頭比例** 的棋子，走在**手繪風景地圖**裡，而不是走在一張攤在桌上的純色紙盤。

這套「標題要有氣勢、盤面要可愛可走」的雙層結構，是它聽起來像商業成品、玩起來又像大富翁的關鍵。本作可以學這個結構，但人物、標誌、金色魔法陣與選單造型都必須重新設計。

### 1.2 地圖才是主視覺，不是介面盒子

原作地圖不是淺色底板加一圈格子，而是：

- 先畫一整張**有地景的世界**（草坪、溪流、樹林、花叢、石頭、建築或主題場景），格子道路是「鋪在風景上的路徑」。
- 每關一張有主題的大地圖。二代地圖比一代更大、更華麗，場景包含山林、花園、都市、海底、雲天、月宮等，並有日夜變化。色彩濃、層次多，看起來像「可以走進的插畫」。
- 格子本身顏色飽和、圖示清楚（起點牌、區塊標記、可愛圖騰），在綠意風景上仍然一眼可辨。

玩家記住的不是 HUD，而是「我走在一幅畫裡」。

### 1.3 角色：盤上 Q 版，狀態列有大頭，事件則靠表情

- 棋盤上的主角是 Q 版站姿，頭身比大約 2.5～3 頭身，服裝可辨識，偶爾帶寵物或配件。
- 畫面角落有**圓形大頭像框**，標示名字與身分（例如職業），讓玩家隨時認得「這是我」。
- 事件、對話、小遊戲則會切到更清楚的角色或場景畫面。神祇登場是「有造型的角色演出」，不是一行系統字。

### 1.4 介面：金色金屬框＋資訊密集，但有「遊戲儀器」的個性

遊玩 HUD 以金綠金屬質感為主，把日期、關卡名、四維（德／智／體／魅）、金錢、體力與操作區都鑲在地圖四周。右側常有一塊較大的操作儀表（指南、系統、行動鈕）。資訊多，但用框線與材質把「遊戲」和「風景」分開。

以 2026 年手機標準來看，這套 HUD **不能原樣搬來**：字太密、觸控熱區不夠、也太接近原作造型。要學的是「框有材質、資訊分區清楚、角色頭像永遠在」，不是學那塊金屬儀器的外形。

### 1.5 色彩與光

- 地圖：高彩度、偏暖的陽光、草綠與花色豐富，暗部仍透明，不走陰鬱厚塗。
- UI：金、暖黃、深綠，像徽章、招牌、漆器，而不是扁平的網站按鈕。
- 格子：紫、黃、藍、橙、白等明確分色，靠圖示輔助，不只靠文字。

### 1.6 小遊戲與事件

小遊戲是短、清楚、場景獨立的 2D 小品（記憶翻牌、限時點擊、跑動收集等），背景與物件都有自己的小舞台，不是在棋盤上彈一個透空視窗就算。事件格則搭配插畫式場景與對話框。

### 1.7 我們要保留的「感覺」（可以學）

| 要保留的感覺 | 意思 |
| --- | --- |
| 走在風景裡 | 手繪地圖是舞台，格子是路上的磁磚，不是 excel 色塊 |
| Q 版棋子 | 盤上角色可愛、好辨識、會跳動或走路 |
| 有表情的人 | 事件、戀愛、神祇、結局都看得到角色臉 |
| 溫暖濃郁 | 色彩飽滿、光是午後或黃金時刻，不灰、不冷漠 |
| 框有質感 | 對話框、頭像框、按鈕像物件，不像網頁表單 |
| 雙層調性 | 標題可以更有氣勢，進遊戲立刻變得親切可玩 |

### 1.8 我們絕不能做的事（法律與風格紅線）

不可複製或「改一點就用」的項目包括，但不限於：

- 任何原作角色（含標題畫面人物、髮型、眼罩／面罩、服裝剪裁與配色）、原作神祇（招財童子、巨靈神、弼馬溫、散財巫婆、瘋狂豬等）與原作怪獸。
- 原作地圖構圖（瑤池、龍宮、廣寒宮等關卡布局）、START 招牌造型、格子上的生物圖示與區塊字母配置。
- `VIRTUAL LIFE II` 標誌、金色魔法陣、米色菱形箭頭選單、右側金屬儀表叢、圓框「User Info」等原作 UI 零件。
- 原作卡片插畫、片頭動畫畫面、字型與文案。

檢驗句：即便沒有寫出「虛擬人生 2」，熟門熟路的玩家也不該指著某一張圖說「這就是從那一幕描過來的」。學的是類型與氣氛，交出的是全新的校園世界。

## 2. 目前網頁版現況（2026-11-18 實機觀察）

現行第一版在玩法上已可走完校園篇，但美術仍是**程式佔位狀態**，這也是畫面看起來陽春的主因。

- **完全沒有插畫檔。** 畫面由網頁字體、色塊、圓角矩形與 emoji 組成，沒有角色圖、地圖圖、圖示精靈或動畫影格。
- **標題頁像雜誌／官網，不像遊戲包裝。** 字級與排版算整齊，主色是乳白底 `#f6f6ee`、森林綠 `#233f36`／`#244d3c`、暖黃 `#f0ce65`，字型為 Noto Sans TC。作為品牌底色其實有潛力，但缺少標誌繪製、主視覺角色與場景，第一眼不像「可上市的遊戲」。
- **棋盤是示意圖。** 淺 Sage 底、一圈淡色橢圓框，格子是約 35～47px 的圓角卡片，靠粉彩分色（遊戲藍、社團綠、小考黃、愛情粉等）加小圖示。沒有地面、建築、光影或路徑材質。玩家不會覺得自己走在校園裡。
- **骰子與角色沒有物象。** 骰子是大號字或色塊；棋子沒有 Q 版人物，多半只是「目前格子被框起來」。
- **事件、神祇、戀愛、小遊戲**缺少專用舞台與角色演出，體驗偏文字冒險，不像二代那種「畫面上發生了一件事」。

結論：現有綠金配色與文字質感可以**升級後沿用為品牌色**，不必整套推翻；真正要補的是「地圖、角色、介面材質、演出特效」這四層。沒有這四層，再怎麼調 CSS 都會像精緻原型，而不是上市作品。

## 3. 原創美術方向提案（三案）與推薦

三案都遵守第 0 與 1.8 節的原創原則，差異在「像二代的程度」與「2026 年上市的第一印象」。

### 方案 A｜青春繪卷・風景棋盤（推薦）

一句話：用手繪校園風景當舞台，Q 版棋子在彩色格子路上走人生，事件與戀愛切到有表情的半身立繪；介面是現代、好按的「漆器／校章」質感，不是 2000 年的金屬儀器。

- **地圖：** 四個求學階段各一張可漫步的手繪校園（見第 4 節），道路以磁磚／石板／花磚鋪在風景上。
- **角色：** 盤上 2.5 頭身 Q 版；事件、戀愛、神祇、結局用 5.5～6 頭身的賽璐璐（平塗＋明確色塊）半身立繪。同一套五官規則，只是比例不同。
- **介面：** 保留現有綠金品牌色，改成有厚度的畫框、校章圓形頭像、紙燈／書籤式對話框、徽章式按鈕。字仍用高可讀的正黑體系，標誌另外繪製。
- **標題：** 可略為戲劇化（主視覺全身或雙人構圖＋校景），但不使用魔法陣、眼罩風角色或金屬選單條。
- **優點：** 最接近二代讓人懷念的核心（走在畫裡、Q 版可愛、事件看得到臉），同時符合 2026 手機遊戲的清晰度與觸控需求；也最利於之後做社會篇擴充。
- **風險：** 地圖與角色量較大，必須分批，但第一批就能讓「看起來像遊戲」。

### 方案 B｜新世紀校園・清爽動畫風

一句話：接近當代校園手機遊戲的乾淨賽璐璐，背景較平整，介面更像現代 App。

- 製作較快、商店截圖很「新」。
- 缺點是懷舊感弱，棋盤容易再變回「漂亮的功能地圖」，少了二代那種「我走在一幅畫裡」的記憶點。
- 若團隊插畫人力很少、必須三到四週內先換皮，可當過渡；不建議當上市定案。

### 方案 C｜復刻金框・精緻 2.5D

一句話：較接近 2000 年商業包的氣勢，Q 版略帶立體明暗，標題走暗底金光與全身主視覺。

- 懷舊最濃，也最容易「看起來像在仿作」。金屬儀表、金圈、暗底金光若造型接近原作，法律與觀感風險都高。
- 在手機直向也較難排得乾淨，容易顯舊。
- **不建議當主風格。** 只建議吸收一點：「標題主視覺可以比盤面更有氣勢」。

### 推薦

**採用方案 A。** 它抓住二代真正讓人記得的東西——手繪風景棋盤、Q 版棋子、會演戲的角色、溫暖濃色——同時用原創的校園世界與現代介面，做出「可上市的新作品」，而不是「縮小版的虛擬人生 2」。現有綠金配色升級後即可作為方案 A 的品牌底色，避免產品識別大翻車。

建議的造型基準（方案 A 定案後作為美術憲法）：

| 項目 | 基準 |
| --- | --- |
| Q 版頭身比 | 約 2.5 頭身，頭大、腿短、手腳可讀、服裝剪影清楚 |
| 立繪頭身比 | 約 5.5～6 頭身，少年少女體態，不成人寫實、不幼齒 |
| 線條 | 中等粗細的穩定勾線，不抖線、不無線平塗 |
| 上色 | 賽璐璐：固有色＋1～2 級陰影＋少量高光，不用厚塗油感 |
| 五官 | 眼睛有神、表情誇張但乾淨；男女共用同一套比例規則，差別在眉眼與五官細節 |
| 光 | 午後暖陽或黃金時刻；大學夜景事件可改成溫燈，但不全面改走暗黑 |
| 禁止 | 寫實照片風、廉價 Q 版貼圖風、過度美型網紅風、陰暗厚塗、賽博龐克、直接模仿原作髮型與配件 |

## 4. 世界與色彩：四個求學階段

每階段一張主地圖，主題必須一看就知道「這是哪個時期」，並為社會篇預留「同一世界變成熟」的延伸，而不是畢業後換一套畫風。

| 階段 | 地圖主題（原創建議） | 主色 | 氣氛 |
| --- | --- | --- | --- |
| 小學教學關 | 晨光校園：低矮教學樓、操場、鳳凰木或榕樹、 chalk 感彩磚路 | 嫩綠、淺黃、天空藍 | 輕、教學、安全、午後遊玩 |
| 國中 | 林蔭學園：走廊、自行車棚、中庭花圃、社團教室外牆 | 新綠、青綠、暖磚橘 | 開始有自己的選擇 |
| 高中 | 坡道與操場：司令台、體育館、秋天的樹、黃昏回家的校門 | 琥珀、茶金、深紅楓、暮橘 | 準備考試、有一點壓力與榮光 |
| 大學 | 河岸或林蔭大道校區：圖書館、噴水池、咖啡館外、夜間也可以很美 | 靛藍、燈金、石白、少量玫瑰 | 戀愛登場、世界變寬 |

製作備註：

- 第一版每張地圖先做 **日間主視覺** 即可；高中黃昏、大學夜景可作為第二批氣氛升級，不必擋第一批換皮。
- 地圖要預留一條清楚的「可行走帶」（寬度足夠放格子與棋子），風景細節放在帶外，避免花朵與建築打斷讀格。
- 岔路在美術上要明顯（分叉的石橋、兩個拱門、左右階梯），讓玩家直覺「這裡要選方向」。
- 愛情格只出現在大學地圖，視覺可在該格用獨特但不過度刺眼的記號（例如校徽緞帶或紙鶴），不要做成原作愛情格的複製品。

## 5. 角色與神祇設計方針

### 5.1 主角（男／女都要）

- 開局可選男性或女性，兩套都是主角規格，不是「男主＋女配」或相反。
- **強烈建議隨學段換裝、微調身高與氣質**（小學→國中→高中→大學），五官骨架固定，讓玩家感到「這個人在長大」。這是人生遊戲最值回票價的視覺投資之一。
- 盤上：Q 版站姿＋短位移／跳躍循環（第一版不必做四向完整走路）。
- 事件：半身立繪，至少 6 種表情（見資產表）。
- 頭髮、校服與隨身物要在小尺寸（棋子 128px）仍可辨識。避免奇異髮色到認不出是校園角色；大學可比小學更有個人風格。

### 5.2 戀愛對象（四檔）

規則：男主角配女伴、女主角配男伴，魅力門檻與薪水檔次相同。美術必須讓四檔「氣場」分得開，但全部是原創校園角色，不可用「比較暴露」當唯一的高檔手段。

| 檔次 | 視覺方針 | 魅力門檻（玩法） |
| --- | --- | --- |
| 輕鬆檔 | 好親近的同學氣質，服裝日常、笑容自然 | 120 |
| 普通檔 | 有記憶點的外形（髮型、配色、社團感），穩健好看 | 200 |
| 亮眼檔 | 校園裡會被多看一眼的人，儀態與配色更完整 | 350 |
| 頂尖檔 | 存在感強、像會站上風采秀舞台，但仍是這個世界的人 | 500 |

建議數量：**四檔 × 兩種性別＝8 人**，每人獨立設計。若要縮預算，可先做每檔 1 人（4 人）並以服裝／髮型變體應付另一性別，但上市完成度仍以 8 人為目標。

每人需要：半身立繪、5 種表情、認識卡／約會用半身、一枚小頭像。不需要盤上棋子（愛情在事件畫面發生）。

### 5.3 小孩

大學才可能出生，第一版畫到**嬰兒＋幼童**即可（社會篇再長）。四種個性要在造型上可辨，不必靠文字才知道：

| 個性 | 造型關鍵（建議） |
| --- | --- |

### 7.3 格式、容量與效能

- **地圖、立繪、CG、照片式背景：WebP。** 透明 UI 與棋子：PNG 或透明 WebP。圖示、框線、可縮放零件：**SVG**。
- 不要把 UI 字刻進圖裡（除了標誌本身）。遊戲內所有文案走字型，方便改數值與之後加語言。
- **首屏預算：** 標題＋UI 套件＋第一張地圖＋當前主角棋子與立繪，壓縮後合計建議 **不超過 8 MB**，目標 4～6 MB。
- **整包 MVP 美術下載預算：** 25～40 MB 可接受（分階段懶載入：進國中再載國中地圖與服裝，戀愛圖進大學再載）。單張地圖 WebP 建議 200～450 KB，單張立繪 80～200 KB。
- 低階手機與模擬器要能順暢走完一回合：地圖用 3 層以內、棋子張數少、特效可關或降級。避免每格一張未合圖的巨大 PNG。
- 色盲與過小尺寸：格子**顏色＋圖示＋短標籤**三者並行，不只靠顏色。
