# 虛擬人生網頁版：青春進行式

純前端的原創求學人生遊戲，以 TypeScript + Vite 製作。主要規格為根目錄的 `MVP企劃_v2.md`；`虛擬人生1+2_玩法規則書.md` 僅作玩法背景參考。沒有使用原作圖片、音效、角色名或敘事文字，題庫為自行撰寫的 200 題。

## 本機執行

需要 Node.js **22.12 以上**（建議 Node.js 22 LTS）與 npm：

```bash
npm ci
npm run dev
```

電腦開啟終端機顯示的網址，通常為 `http://localhost:5173`。

同一區域網路的手機可開啟 `http://電腦的區域網路IP:5173`。MuMu 模擬器內的瀏覽器可開同一個區域網路 IP；請確認電腦防火牆允許該連線。部署到 Pages 後，各裝置直接開啟正式網址即可，不需要安裝 App。

```bash
npm run build    # TypeScript 型別檢查與正式打包
npm run preview  # 在本機預覽 dist/
npm test         # 遊戲規則、完整人生與存檔驗證
npx playwright install chromium
npm run test:browser  # 瀏覽器操作與響應式測試
```

若系統已有 Chromium，可指定路徑，例如 `CHROMIUM_PATH=/usr/bin/chromium npm run test:browser`。Linux 若缺少瀏覽器套件依賴，可在允許安裝的環境執行 `npx playwright install --with-deps chromium`。

## 怎麼試玩

1. 按「開啟我的人生」，輸入名字，選擇性別、生日及血型。右側即時預覽星座、季節與四維加成。
2. 小學有 6 步教學，不占正式求學回合；也可略過。擲骰、閱讀事件、選擇岔路，完成活動後按「繼續」。
3. 國中必選社團，開始 **15 回合**。升高中考試 **10 題答對 6 題**即通過；失敗直接進入國中學歷結算，不可重考。
4. 高中 **25 回合**，最後一回合強制聯考，規則相同。聯考通過可在大學玩 **40 回合**，回合到就畢業。
5. 社團格加四維，小考 5 題；遊戲格隨機一款，連玩 3 局依勝場領獎。右下的「小遊戲練習室」可單獨體驗 8 款，練習不發正式獎勵。
6. 虛擬城大賽每場三選一，國中、高中各 1 場，大學 2 場；踩到大賽格可提早參賽，指定回合會保底出現。
7. 大學的愛情格可認識對象。魅力與現金需達門檻，認識後約會不再收費。對象的喜好提示會顯示在交往面板。愛情度 **99** 可求婚；結婚下一回合開始薪水及懷孕判定。
8. 上方「成長手札」可隨時一鍵查看四維、金錢、逆行、泰來與神祇；「戀愛與家庭」查看懷孕、小孩與支出；「收藏與履歷」查看社團、成績及卡片。
9. 從「存檔與進度」使用 **1 自動 + 3 手動槽**，亦可匯出 JSON，於另一台裝置匯入。首頁按「繼續旅程」恢復自動槽。

## 已實作的規則

- 起始四維各 80、現金 5,000。十二星座、四種血型與季節加成；生日包含 2 月 29 日。
- 平常兩顆六面骰，每回合 5% 機率逆行 3 回合。逆行中再中不延長，到期後獲得 3 回合泰來；好事與好神祇權重改為 2:1，神祇事件的 15% 基礎機率不變。逆行與泰來可以重疊。
- 岔路在移動途中暫停，選邊後消耗剩餘步數；迷途使會隨機選邊。步數童可在當回合實際骰子範圍內指定步數。
- 7 位原創神祇，同時 1 位，可到期、被取代或在事件格還願。新附身於本回合結束不扣時數，下一回合開始結算。
- 200 題原創四選一，五類各 40 題，含難度與解析。小考用易題、升高中難題 20%、聯考與智囊搶答難題 40%，優先抽未看過的題。智力達 150 時提供排除一個錯誤選項的提示，通過標準仍為 6 題。
- 智囊搶答依答對數、作答用時、智力排序；風采秀以魅力與搭配選項計分；衝刺擂台使用節奏拍擊。對手依階段設定產生。
- 結婚後每回合 10% 機率懷第一胎，之後每次生產降為原本的十分之一；孕期 6 回合，25% 機率雙胞胎。懷孕與生產回合不重複判新孕，懷孕當回合起收一份 600，出生當回合起每位小孩 600。小孩各有四維及個性，可在家庭事件成長。
- 現金及四維最低 0，不因破產結束。事件可獲得經驗與原創收藏卡，卡片第一版不進行戰鬥。

## GitHub Pages 部署

已加入 `.github/workflows/pages.yml`：

- PR：安裝套件、規則測試、型別檢查、打包及 Chromium 瀏覽器測試。
- 合併或推送至 `main`：上述檢查通過後，自動部署 `dist/` 至 GitHub Pages。
- 也可由 Actions 手動執行。PR 本身不會發布正式網站。

**儲存庫管理員首次需到 Settings → Pages → Build and deployment，將 Source 選為 GitHub Actions。** 此設定未啟用前，部署工作可能失敗。此 repo 目前為私有，GitHub 帳號方案須支援私有儲存庫 Pages，否則需由管理員決定方案或可見性。

預期正式網址：`https://andyliu0817.github.io/virtual-life-web/`。**合併且部署成功後才可試玩，這不是 PR 預覽網址。** Vite 使用相對資源路徑，同時支援 Pages 子目錄與一般靜態主機。

## 修改文字、美術與數值

| 檔案                           | 用途                                                           |
| ------------------------------ | -------------------------------------------------------------- |
| `src/data/config.ts`           | 回合、機率、獎勵、生日加成、社團、神祇、對象、小遊戲設定與地圖 |
| `src/data/text.ts`             | 通用繁體中文、事件敘述、戀愛問題及顯示名稱                     |
| `src/data/ui.ts`               | 首頁、篇章及介面裝飾文字                                       |
| `src/data/questions.ts`        | 200 題題庫、四選一、難度及解析                                 |
| `src/game/types.ts`            | 可延伸的角色與存檔型別                                         |
| `src/game/engine.ts`           | 與畫面無關的回合狀態機，可注入亂數測試                         |
| `src/game/minigames.ts`        | 8 款點擊小遊戲與動畫生命週期                                   |
| `src/game/storage.ts`          | 版本化 JSON、資料驗證、4 個本機槽位                            |
| `src/main.ts`、`src/style.css` | 介面與原創幾何美術；可替換成正式素材                           |

不依賴外部字型、圖片或音效服務，正式打包後不需要遊戲後端。所有操作均可用點擊或觸控，直向與橫向以響應式版面呈現。

## 存檔與社會篇擴充

存檔外層為 `{ format: "virtual-life-web", version: 1, savedAt, state }`；Zod 驗證數值、日期、列舉、題目 ID 及主要階段一致性。未知版本拒絕讀入，後續升版應先新增遷移器，不應靜默清除進度。

`state` 保存角色開局資料、四維、金錢、等級／經驗、學歷、社團履歷、成績、卡片、神祇、逆行／泰來、交往與婚姻、懷孕起始回合、小孩個性與四維，以及當前回合互動。`future` 預留章節、職業履歷、股票部位、戰鬥牌組與 HP、小孩守護天使 ID、自訂擴充欄位。地圖類型也預留轉職、發薪、旅行、房產、研究所、怪獸及任務，第一版不放置。

結算只改為 `stage: "society"`、`phase: "end"` 及學歷旗標，不清空任何角色、家庭或狀態。國中學歷依 v2 文末最新決定，**不直接開放隱藏職業**；高中落榜可走隱藏職業，大學畢業可走知識型職業，完整職業鏈留待社會篇。

自動槽於擲骰前寫入，並在選擇、答題及結算等進度點更新，以避免重整重複發獎。小遊戲中途重整或開啟其他面板會回到該局起點，不會重發已完成局數的獎勵。存檔不儲存影格、倒數動畫；裝置時鐘不作為懷孕或神祇的經過時間，這些只依回合推進。**瀏覽器清除網站資料、無痕模式結束或更換網址都可能失去本機槽位，請用匯出備份。**

## 驗證範圍與限制

自動化涵蓋從小學到大學完整 80 正式回合、兩種升學失敗結局、恰好 6 題通過、題庫與難度、岔路、骰子狀態、神祇、家庭、存檔往返與損毀拒收。瀏覽器測試涵蓋角色建立、重整恢復、槽位、匯入匯出、8 款練習入口及 320／390／844／1280 寬度。MuMu 的實機 Android 瀏覽器、不同手機效能與長時間遊玩仍需人工驗收。

第一版不包含轉職、股票交易、卡片戰鬥、二代闖關、房產或輪迴；結算會明確預告可延續到社會篇。
